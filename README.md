# 抖音下载（飞牛 fnOS 原生应用）

在电脑浏览器的抖音网页版点一下书签，或者在手机抖音里把作品分享给 NAS，就能把视频（无水印）下载到飞牛 NAS。

## 工作方式

```
抖音网页版 (https)            飞牛 NAS :8866 (http)
┌──────────────────┐  弹窗   ┌────────────────────────┐
│ 书签小工具读取     │ ─────▶ │ /add 接收视频地址       │
│ <video> 的播放地址 │  GET   │ 后台下载到共享目录       │
└──────────────────┘        │ DouyinDL/videos        │
                            └────────────────────────┘
```

- 截至 2026-10，抖音分享页不再直接输出视频数据，接口也需要浏览器安全 SDK 生成签名，
  所以本应用不去解析分享链接，而是直接读取网页版播放器正在播放的视频地址。网页版的视频流本身没有水印。
- https 页面不能直接请求 http 的 NAS（混合内容会被拦截），所以书签用弹窗打开 NAS 的 `/add` 页面来传递地址。
- 桌面入口走飞牛 CGI：`/cgi/ThirdParty/DouyinDL/index.cgi/`，由 `app/ui/index.cgi` 转发到本机 8866。
  这样使用飞牛自己的域名和端口，FN Connect、域名、反代等远程方式都能打开，并由飞牛校验登录。
  局域网里也可以直接访问 `http://NAS地址:8866/`。
- 视频地址带时效签名，需要在页面打开后的较短时间内发送；过期了回到页面刷新后再点一次书签即可。

## 目录

| 路径 | 说明 |
| --- | --- |
| `manifest` | 应用信息，端口 8866，依赖 `nodejs_v22` |
| `cmd/main` | 启动 / 停止 / 状态 |
| `config/resource` | 声明共享目录 `DouyinDL/videos` |
| `app/server/server.js` | 下载服务（只用 Node 标准库） |
| `app/server/resolve.js` | 分享链接解析（调用 NAS 上的 Chromium） |
| `app/ui/index.cgi` | 飞牛 CGI 入口，转发到本机下载服务 |
| `app/www/` | 管理页、书签接收页、书签源码 |
| `tools/make-icons.js` | 生成图标 |
| `tools/fix-perms.sh` | 修正 Windows 打包后丢失的 cmd/ 与 index.cgi 可执行权限 |

## 打包

```bash
fnpack build
```

在 Windows 上打包后还需要执行：

```bash
bash tools/fix-perms.sh DouyinDL.fpk
```

## 安装与使用

1. 应用中心 → 手动安装 → 选择 `DouyinDL.fpk`（会自动安装依赖 Node.js v22）。
2. 打开「抖音下载」，把「存到 NAS」按钮拖到浏览器书签栏。
3. 在 www.douyin.com 播放视频，点书签；首次使用时允许 douyin.com 打开弹出窗口。
4. 视频默认保存在共享目录 `DouyinDL/videos`，也可以在应用页面里播放、下载或删除。
5. 想保存到自己的文件夹：从飞牛桌面打开「抖音下载」，在页面底部「保存位置」点「选择文件夹」。会跳到飞牛的文件夹选择页，
   选好后如果应用还没有这个文件夹的权限，会再跳到飞牛的授权确认页（需管理员），确认后跳回保存（App Auth `pick-file` + `authorize-shared-file`）。也可以在「系统设置 → 应用 → 抖音下载 → 访问权限」
   手动添加文件夹后填写路径。设置保存在 `settings.json`，只影响之后的下载。

### 分享链接下载（手机推荐）

需要 NAS 上装有 Chromium（SSH 执行 `sudo apt install chromium`）。NAS 收到分享链接后，用无头 Chromium
打开抖音电脑版作品页，截获页面自己发出的作品详情请求（带抖音的签名），取出无水印地址再下载，见 `app/server/resolve.js`。
抖音的接口直接请求会被风控拦截，所以只能借助真实浏览器。

- **管理页**：把抖音「分享 → 复制链接」得到的内容粘贴到「粘贴链接下载」，点「下载到 NAS」。
- **iPhone 快捷指令**（手机需和 NAS 在同一局域网）：新建快捷指令，在详细信息里打开「在共享表单中显示」，
  「如果没有输入」选「获取剪贴板」；添加「获取 URL 内容」（地址 `http://NAS地址:8866/api/share`，方法 POST，
  请求体 JSON，字段 `text` = 快捷指令输入）和「显示通知」（内容 = URL 的内容），命名为「存到NAS」。
  之后在抖音里「分享 → 更多」选「存到NAS」，或复制链接后运行它即可。

`/api/share` 接受 JSON、表单、纯文本或 `?text=`，默认返回一行纯文本结果（方便快捷指令显示通知），加 `?json=1` 返回 JSON。

## 本地调试

```bash
cd app/server && SAVE_DIR=./videos TRIM_PKGVAR=./var node server.js
```

如果你的电脑需要走代理才能上网，请加上 `NODE_USE_ENV_PROXY=1`。

## 限制

- 支持普通视频；直播和图集暂不支持。
- 快捷指令走局域网直连端口，不带飞牛登录，在外网时用不了；外网可以打开管理页粘贴链接下载。
- 服务没有登录鉴权，只应在局域网内使用，不要把 8866 端口映射到公网。
- 请只下载自己有权保存的内容，尊重创作者版权。
